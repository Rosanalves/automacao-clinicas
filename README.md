# 🏥 Automação Completa para Clínicas e Consultórios

> Sistema end-to-end de automação para clínicas estéticas e consultórios médicos.
> Do primeiro contato do paciente até a reativação — tudo automatizado.

---

## 🎯 O que este projeto resolve

A maioria das clínicas perde pacientes e dinheiro por falhas em processos que 
poderiam ser 100% automatizados. Este sistema resolve isso de ponta a ponta.

| Problema | Solução |
|----------|---------|
| Demora no atendimento | Chatbot 24/7 via WhatsApp |
| Paciente falta sem avisar | Confirmação automática 48h antes |
| Orçamento enviado e esquecido | Follow-up automático em D+1, D+3 e D+7 |
| Paciente sumiu após procedimento | Sequência de pós-venda automatizada |
| Base de pacientes inativos | Campanha de reativação inteligente |
| Informações espalhadas | CRM centralizado com histórico completo |

## 🔄 Áreas cobertas pelo sistema

- ✅ **Atendimento** — Chatbot, triagem e FAQ automatizado
- ✅ **Agendamento** — Online 24/7 com confirmação automática
- ✅ **Orçamentos** — Envio profissional com follow-up inteligente

- ✅ **Pós-Venda** — Cuidados, avaliação e programa de indicação

## 💼 Modelos de Contratação

### Modelo 1 — Serviço + Implementação
Para clínicas que querem tudo pronto e configurado.
- Diagnóstico + configuração + treinamento + suporte
- **Investimento:** R$ 3.000 a R$ 8.000 + mensalidade

### Modelo 2 — Só a Automação
Para agências e freelancers que querem implementar sozinhos.
- Fluxos prontos + documentação + templates + vídeos
- **Investimento:** R$ 497 a R$ 1.997
